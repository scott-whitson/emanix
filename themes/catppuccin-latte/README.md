# Catppuccin Latte (light)

The light half of the Catppuccin palette. Variant: **light**.

## Colors

This theme is generated from `colors.toml` (single source of truth):

- `pi-agent-theme.json` — regenerated by `dot-theme-set` via `bin/gen-pi-theme.py`
- The remaining per-app files (ghostty, btop, gtk) reference the same palette

## Activate

    dot-theme-set catppuccin-latte

## Optional enhancements

- **GTK apps:** `gtk.conf` sets `Adwaita` by default. Replace with a
  Catppuccin Latte GTK theme if installed.

Emacs (and the EWM top bar with it) is themed by `scott/theme-set` in the running
daemon, not by a file here. The Neovim and Obsidian notes were dropped on
2026-08-08 — neither is installed any more.

Source: <https://catppuccin.com/palette>
