# Catppuccin Latte (light)

The light half of the Catppuccin palette. Variant: **light**.

## Activate

    dot-theme-set catppuccin-latte

## Optional enhancements

- **Neovim:** install the `catppuccin/nvim` plugin in your kickstart fork; same
  config as for Catppuccin Mocha. The plugin supports both flavors.
- **Obsidian:** install the community "Catppuccin" theme and edit
  `themes/catppuccin-latte/obsidian-theme` to `Catppuccin` (latte flavor).
  Otherwise ships with Obsidian's built-in "moonstone" light theme.
- **GTK apps:** `gtk.conf` sets `Adwaita` by default. Replace with a
  Catppuccin Latte GTK theme from AUR if installed.

Source: https://catppuccin.com/palette
