# Implementation plans

Live plans sit here. Completed ones move to [`archive/`](archive/) so this
directory shows what is actually in flight.

Plans are dated decision records: they are not edited to match what shipped.
Where implementation diverged, the *spec* carries an "as-built correction"
section — see `docs/superpowers/specs/2026-08-07-eminix-convergence-design.md`,
whose correction records that its central premise about datacore was wrong.

Nothing is in flight as of 2026-08-08. The next likely plan is the datacore
NixOS cutover onto the HP that `zord-old` used to run
(`specs/2026-08-05-datacore-nixos-design.md`).
